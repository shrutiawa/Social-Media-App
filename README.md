# 🌐 SocialSphere - A Modern Social Media App

SocialSphere is a responsive, real-time social media platform where users can share posts, view trending news, and interact with others. 
Built with a modern tech stack including **Next.js**, **MongoDB**, **NextAuth**, and **Redux**, it offers a smooth and scalable user experience.

## 🚀 Features

- 📝 User authentication (Sign up / Login with NextAuth)
- 🔐 Forgot Password with OTP verification
- 🧠 Redux-powered global state management
- 📸 Post creation and feed display
- 🔥 Trending news section (auto-updates every minute)
- ⏱ Real-time updates without page refresh
- 📱 Fully responsive UI for mobile and desktop

## 🛠 Tech Stack

- **Frontend**: Next.js, Tailwind CSS
- **Backend**: Node.js (API Routes)
- **Authentication**: NextAuth.js
- **Database**: MongoDB
- **State Management**: Redux Toolkit
